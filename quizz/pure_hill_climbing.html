Pure Hill Climbing

A short instructional note on the local-search form of hill climbing: what it does, where it fails, and how it differs from the modern (OPEN-list) hill climbing used in many lecture notes — including this course’s Week 3 slides.

Audience
Students who have seen heuristic search
Related lab

Primary textbook
Russell & Norvig, AIMA

The idea

Pure hill climbing (also called steepest-ascent or greedy local hill climbing) is a local search method. At every step it looks only at the current state and that state’s immediate neighbors. It moves to the neighbor that looks best according to a heuristic h(n), and it forgets every alternative it did not take.

There is no fringe, no OPEN list, and no backtracking. The algorithm is therefore extremely cheap in memory — but it can stop forever at a local minimum even when a path to the goal still exists elsewhere in the graph.

Core message

A heuristic can point you toward improvement; it cannot invent memory. Pure hill climbing trades completeness for simplicity: if the next step does not look better, it stops.

The algorithm

Assume we are minimizing h(n) (estimated remaining cost to the goal; goal has h = 0).

Pure Hill Climbing (steepest ascent / descent)
  1. Set current ← start state.
  2. Generate all neighbors of current.
  3. Let best be the neighbor with the lowest h.
  4. If h(best) < h(current), move: current ← best, and repeat from step 2.
  5. Otherwise stop. If current is the goal, succeed; else report failure at a local minimum.

Important consequences of this rule:

  • Only one node is stored as “current.”
  • Siblings that looked slightly worse are discarded immediately.
  • The algorithm never revisits an earlier fork in the road.
  • It does not track path cost g(n) — only the local heuristic signal.

At Trap, every neighbor has a worse heuristic. Pure hill climbing has no OPEN list left to consult, so it reports failure — even though Goal is still in the graph, waiting behind the discarded branch through K.

Local minimum

A node whose heuristic is better than (or equal to) all of its neighbors. Pure hill climbing cannot leave such a node: by definition, no improving move exists, and no alternative path is stored.

Pure vs modern hill climbing

The name “hill climbing” is used in two related but different ways in AI courses. This section separates them so the Week 3 slides and the Week 4 local-search labs do not contradict each other.

Pure hill climbing

Local search. Keep only the current node. Move to a strictly better neighbor or stop. This is the definition in Artificial Intelligence: A Modern Approach (Russell & Norvig), Chapter 4.

Modern / lecture-slide hill climbing

Heuristic depth-first search: keep an OPEN list, sort a node’s children by h, and push that sorted list onto the front of OPEN. This is the procedure in slides/2.Searching_2.pdf, and the classical Winston / MIT 6.034 formulation (“hill climbing with backup”).

In this course we call the OPEN-list version modern hill climbing because it is the form presented in the heuristic-search lecture (and in many older university notes that teach “Best-First = BFS + h” and “Hill Climbing = DFS + h”). Pure hill climbing is the stricter local-search rule used when we study why local search fails.

Property Pure hill climbing Modern hill climbing (slides)
Uses h(n)? Yes Yes
Maintains OPEN / fringe? No — current node only Yes — stack-like OPEN
How children are used Keep only the best improving neighbor Sort all children by h, insert at front of OPEN
Can backtrack? No Yes (via remaining OPEN entries)
On the Trap example Stops at Trap; misses Goal Can later expand K and still reach Goal
Memory Minimal (O(1) beyond the path itself) Like DFS — fringe can grow with branching
Guaranteed to find a goal? No — local minima / plateaus No — same incompleteness risks as DFS, but not “stuck with empty memory”
Closest textbook name AIMA “hill-climbing search” Heuristic DFS / Winston hill climbing

Same graph, different outcomes

On Figure 1, both methods prefer the left branch early because h(A) = 15 < h(K) = 18. The difference appears only after Trap:

  • Pure: neighbors F and G look worse → stop. Branch K was never stored.
  • Modern (slides): after exploring the left dead-end, OPEN still holds earlier alternatives (for example K). The search can continue and find Goal.

So the modern method is “hill climbing” only in the weak sense that it prefers the locally best child first. It is really DFS guided by a heuristic, not pure local search.

Naming note

AIMA reserves the name “hill climbing” for the pure local version. Poole & Mackworth call the OPEN-list version heuristic depth-first search. Both names are historically published; what matters for exams is which rule you are asked to apply.

What to remember

  1. Pure hill climbing = local improvement only. No OPEN list, no backtracking.
  2. Its characteristic failure mode is the local minimum (as at Trap).
  3. Modern / lecture-slide hill climbing = DFS + sort children by h into OPEN. It can recover from a bad branch.
  4. When a question says “hill climbing,” check the context: Week 3 slides → modern (OPEN) form; Week 4 local-search labs → pure form.
